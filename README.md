# PCA 0→Hero

Plateforme d'apprentissage interactive sur le **Plan de Continuité d'Activité (PCA)**, la norme **ISO 22301** et le **BIA** : cours en français avec explications en darija tunisienne, schémas interactifs, quiz corrigés, glossaire, examen blanc.

Une seule page HTML autonome : ouvrez `index.html` dans un navigateur, aucune installation.

Outil d'étude non officiel, sans lien avec l'ISO. Pour le texte exact de la norme, consultez l'exemplaire officiel.

Si le projet vous aide, mettez une ⭐ au repo.
